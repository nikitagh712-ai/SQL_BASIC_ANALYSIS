# Chinook SQL Analysis Project

## Project Overview
This project focuses on analyzing the Chinook music database using SQL to extract meaningful business insights related to customer behavior, sales performance, music trends, and revenue generation.

The analysis was performed using MySQL Workbench and includes advanced SQL concepts such as joins, aggregate functions, subqueries, Common Table Expressions (CTEs), and window functions.

## Sample SQL Query

```sql
SELECT 
    c.CustomerId,
    CONCAT(c.FirstName,' ',c.LastName) AS fullname,
    c.Country,
    SUM(i.Total) AS totalspent,
    DENSE_RANK() OVER(
        PARTITION BY c.Country
        ORDER BY SUM(i.Total) DESC
    ) AS ranking
FROM customer c
JOIN invoice i
ON c.CustomerId = i.CustomerId
GROUP BY c.CustomerId, c.Country;
```
